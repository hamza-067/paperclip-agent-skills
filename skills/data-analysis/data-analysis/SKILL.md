# Data Analysis

## Workflow
1. Define the decision question, target population, unit of analysis, and success metric.
2. Inspect schema, data types, missingness, duplicates, ranges, outliers, and data provenance.
3. Preserve the original data; document cleaning and transformations.
4. Check for sampling bias, leakage, inconsistent units, and time-window mismatches.
5. Use suitable descriptive statistics and visualizations; choose methods based on data type and assumptions.
6. Separate correlation from causation. Report uncertainty and limitations.
7. Validate calculations with spot checks or independent recomputation.
8. Present key findings first, with charts/tables, practical implications, and recommended next steps.
9. Provide reproducible code or formulas where useful.

## Deliverables
Data-quality report, methodology, findings, visualizations, limitations, and reproducible artifacts.

## Safety
Minimize personal data. Do not upload sensitive data to unapproved services. Do not make high-impact decisions about individuals solely from an unvalidated model.
