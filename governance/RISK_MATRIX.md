# Risk Matrix

| Level | Examples | Minimum control |
|---|---|---|
| Low | Brainstorming, summarizing public docs, drafting internal outlines | Self-check and cite sources where relevant |
| Medium | Marketing recommendations, analytics, code changes in a test branch | Evidence, tests, privacy check, reviewer for important changes |
| High | External outreach, production deployments, customer records, security controls, financial actions | Explicit authorization, least privilege, audit trail, human review, rollback plan |
| Prohibited | Secret exfiltration, deceptive impersonation, unauthorized access, harmful malware, evading safeguards | Reject and explain briefly |

Risk depends on context, data, tools, and consequences—not merely the skill's category.
